# VSTEP Reading B1+ – Work & Employment – HỌC VIÊN

## Upload lên GitHub Pages

1. Giải nén gói ZIP này trên máy tính.
2. Mở repository GitHub muốn sử dụng. Chọn **Add file → Upload files**.
3. Upload toàn bộ 6 file bên dưới **ngang hàng ở thư mục gốc**, rồi Commit changes. Không upload nguyên file ZIP.
4. Vào **Settings → Pages**, chọn **Deploy from a branch → main → / (root) → Save**.
5. Mở đường dẫn GitHub Pages do GitHub hiển thị sau khi xuất bản hoàn tất.

Các file ngang hàng: `index.html`, `style.css`, `script.js`, `logo-cfl.jpg`, `logo-35-years.jpg`, `README.md`.

Không cần tạo thư mục con, cài đặt phần mềm hay chạy build. Có thể mở `index.html` trực tiếp trên máy tính. Font Be Vietnam Pro đã được nhúng trong `style.css`.

## Nội dung và thao tác

- Chủ đề: **Work & Employment**; 4 passages.
- Mỗi passage có **10 Reading Questions** và **20 B2 Paraphrase Challenge** đúng theo file Word nguồn.
- Giữ nguyên các chức năng: đổi cỡ chữ, timer 15 phút theo passage, Highlight, Dictionary, phát âm, lưu tiến độ trong trình duyệt, Previous/Next, Reset all.
- Nút Check this passage chỉ hiển thị Correct / Incorrect / Not answered và điểm số, không hiện đáp án.
- Hai logo nằm ngang hàng với các file còn lại và được gọi bằng đường dẫn tương đối, phù hợp GitHub Pages.

## Lưu ý khi dùng hai phiên bản

Bản Học viên và bản Giáo viên đều dùng tên file giống nhau. Nếu muốn xuất bản đồng thời hai đường dẫn, hãy dùng **hai repository GitHub khác nhau**.

Đây là trang luyện tập tĩnh: chấm bài diễn ra trong trình duyệt, không gửi kết quả về giáo viên và không có đăng nhập.
